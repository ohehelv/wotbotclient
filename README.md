# WoT Sandbox — оффлайн-бой с ботами для World of Tanks

Мод для клиента World of Tanks: локальный бой на настоящей карте против простых ботов, без подключения к серверу.

Проверено на клиенте **EU 2.4.1.0** (Steam). На других версиях папка мода называется по номеру версии (`res_mods/<версия>/`), и мод может потребовать доработки.

## Установка

1. Скачайте репозиторий: **Code → Download ZIP** и распакуйте, или `git clone https://github.com/ohehelv/wotbotclient`.
2. Запустите `install.bat`. По умолчанию он ставит мод в
   `C:\Program Files (x86)\Steam\steamapps\common\World of Tanks\eu`.
   Если игра стоит в другом месте, укажите путь к папке с `WorldOfTanks.exe` и `res_mods`:
   ```
   install.bat "D:\Games\World of Tanks\eu"
   ```
   Если копирование не удалось, запустите `install.bat` от имени администратора.

Вручную: скопируйте содержимое `release\eu\` в папку игры `World of Tanks\eu\`.

## Запуск

- `sandbox_bots.bat` — бой с ботами.
- `sandbox_freecam.bat` — встроенный режим разработчика: карта и свободная камера, без танков.
- `sandbox_native.bat` — **эксперимент**: родной боевой клиент игры (настоящий интерфейс боя, миникарта, маркеры) с сервером, эмулированным внутри мода. Подключение к серверам Wargaming в этом режиме заблокировано. Пока в разработке.

Если вместо боя открылся лаунчер, нажмите в нём «Играть». `.bat` оставляет рядом с игрой файл `sandbox_launch.txt` с настройками, мод читает его при старте и удаляет. Если закрыть лаунчер, не запустив игру, удалите `sandbox_launch.txt` из `eu\` и `eu\win64\`, иначе следующий обычный запуск тоже откроет песочницу.

При обычном запуске игры мод ничего не делает.

## Управление

| Клавиша | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D | повороты |
| Мышь | обзор и наведение |
| ЛКМ | выстрел |
| 1 / 2 / 3 | тип снаряда |
| 4 | ремкомплект |
| Shift / ПКМ / колесо | снайперский режим |
| F1 | подсказка |
| F5 | новый бой |
| Enter | новый бой после победы или поражения |
| Esc ×2 | выход из игры |

## Настройки

Параметры задаются в строке `echo ...` внутри `sandbox_bots.bat`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `map` | `05_prohorovka` | карта: `01_karelia`, `02_malinovka`, `04_himmelsdorf`, `10_hills` и др. (имена из `res\packages`) |
| `tank` | `germany:G04_PzVI_Tiger_I` | ваш танк, `нация:Имя`, например `ussr:R04_T-34`, `usa:A05_M4_Sherman` |
| `bots` | `6` | число противников |
| `allies` | `0` | число ботов-союзников |
| `difficulty` | `1.0` | точность ботов, 0.5–2 |
| `dmg` | `2.0` | множитель вашего урона |
| `pen` | `0.95` | шанс пробития ваших снарядов (0–1) |
| `repairs` | `3` | ремкомплектов на бой |
| `repairhp` | `0.4` | доля прочности, которую восстанавливает ремкомплект |
| `tracks` | `1` | экспериментальная анимация гусениц, `0` — выключить |

## Что сделано и что нет

Сделано:
- оффлайн-загрузка карты;
- модели танков из игры;
- езда с учётом рельефа;
- баллистика снарядов;
- все типы снарядов орудия с боекомплектом;
- ремкомплекты;
- упрощённая броня (лоб, борт, корма из ТТХ);
- боты (сближение, удержание дистанции, манёвры, проверка видимости, стрельба с разбросом);
- маркеры над танками и HUD: панель снарядов и ремкомплекта внизу, перезарядка под прицелом, надписи «ПРОБИТИЕ / НЕ ПРОБИЛ / РИКОШЕТ» и всплывающий урон над целью;
- эффекты попаданий и разрывов;
- экспериментальная анимация гусениц (как в кил-каме игры).

Пока нет:
- звуков;
- точной брони по коллизионным моделям (клиент не может их загрузить, используются «коробки» корпуса и башни);
- модулей и экипажа.

## Логи

Сообщения мода пишутся в `World of Tanks\eu\game.log` с пометкой `[SANDBOX]`.

## Сборка из исходников

Исходник: `src/mod_sandbox.py`. Игра использует Python 2.7, поэтому компилировать нужно им же:

```
PY27=/path/to/python2.7 ./build.sh
```

Скрипт прогоняет `tests/mock_engine_test.py` (имитация движка) и кладёт `mod_sandbox.pyc` в `release/`.

## Важно

Мод работает только локально и не подключается к серверам Wargaming. Используйте его на свой риск. Проект неофициальный и не связан с Wargaming.
